把 AI 当聊天框用，是低估了它。把它当成一个**能动手的助手**，世界就变了。

## MCP 是什么

MCP（Model Context Protocol）是一个让 AI 调用外部能力的协议。简单说，你可以把「操作域名」「操作服务器」「读写文档」这些能力，打包成一个个工具，挂载给 AI。

挂载之后，AI 不再只是「告诉你怎么做」，而是**直接替你做**。

## 我现在挂载了什么

举几个例子：

- **Cloudflare MCP**：用自然语言增删改域名解析
- **飞书 CLI**：让 AI 操作我的文档、表格、日历
- **文件系统**：AI 直接读写本地项目

这些能力组合起来，AI 就能完成「写一篇文章 → 排版 → 发布到网站 → 同步到文档」这种跨工具的链路。

## 工具之间还能互调

更有意思的是，工具之间可以互相调用。

Claude Code 可以调 Codex，Codex 可以调 GLM，谁擅长什么就交给谁。配置不会？让 AI 帮你写一个 MCP 桥接，完全可行。

> 一套 MCP，多个模型复用。AI 不再是孤岛，而是一个能协作的网络。

## 一个建议

如果你还没开始，挑一件**最重复的事**，让 AI 接手。

一旦你尝过「说一句话，事情就办了」的甜头，就再也回不去了。
