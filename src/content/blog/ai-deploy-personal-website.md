这不是一篇教程，而是一份真实的记录：这个你正在浏览的网站，是怎么在半小时内从零到上线的。

## 以前卡在哪里

我以前总觉得，独立部署一个网站需要懂很多运维：Nginx 配置、DNS 解析、HTTPS 证书、防火墙……每一样都够折腾半天。于是想法一直停在脑子里。

后来我发现，这些事情 AI 都会，而且做得比我快。

## 整个流程其实就两把钥匙

让 AI 自己干活的本质，是把它需要的能力交给它：

1. **SSH 访问权**：AI 用命令行操作服务器，装环境、跑代码
2. **域名 API**：AI 调用 Cloudflare 接口，自动改解析

拿到这两样，建站就变成了对话。

## 实际发生的事

我对 AI 说：做一个「现代技术感 + 暗色主题 + 流光特效」的个人网站，部署到 `jack.codeshow.cc`，原静态站保留。

然后 AI 依次完成了：

- 选定技术栈（Astro + React + Tailwind + Framer Motion）
- 写出所有页面和交互特效代码
- 本地构建出静态文件
- 通过 SSH 部署到 VPS
- 通过 Cloudflare API 加好子域名解析
- 开启 HTTPS，验证访问

## 一个观念的转变

> 以前是「我学会了什么，才能做什么」。现在是「我想做什么，让 AI 帮我学会什么」。

这不会让你变成什么都不懂的废人，反而让你敢去碰以前不敢碰的领域。运维如此，设计如此，很多事情都如此。

下一站，我想让它自动写文章、自动部署、自动备份。让循环转起来。
